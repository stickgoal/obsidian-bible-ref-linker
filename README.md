# Bible Ref Linker

Obsidian 插件：渲染时自动把圣经引用转换为内部链接。

## 支持的格式

| 输入示例 | 链接目标 |
|---|---|
| `太 25:36` / `太25:36` / `太 25：36` | `[[马太福音 25#36]]` |
| `太 25:36-38`（范围） | `[[马太福音 25#36]]`（取第一节） |
| `太 25:36、38、41`（顿号列表） | 36 / 38 / 41 **各自独立链接**到对应节 |
| `太 25:36,38,41` / `太 25:36，41`（逗号列表） | 同上 |
| `太 25:36; 26:1`（分号跨章） | `[[马太福音 25#36]]` + `[[马太福音 26#1]]`，分号后可省章号（`; 38`） |
| `马太福音 25:36`（中文全名） | `[[马太福音 25#36]]` |
| `Matt 25:36` / `Mt 5:3` / `Jn 3:16` / `1Co 13:4`（英文缩写） | 链接到对应中文全名 |
| `Matthew 5:3` / `1 Samuel 1:1` / `Song of Solomon 3:1`（英文全称） | 链接到对应中文全名，大小写不敏感 |
| `太 25章36节` / `创 1章1节`（中文章节字） | `[[马太福音 25#36]]` |
| `太 第25章`（仅章） | `[[马太福音 25]]` |
| `诗 23篇` / `诗 23篇1节`（诗篇"篇"计数） | `[[诗篇 23]]` / `[[诗篇 23#1]]` |

覆盖和合本 66 卷书：中文全名、中文缩写（太 / 创 / 撒上 / 约壹 / 约一 …）、英文缩写与全称。

- **打开页面 / 编写时实时渲染**（Live Preview）：内置 CM6 编辑器扩展，打开文件、每次击键/移动光标都会自动重扫光标行——输入 `太 25:36 ` 后（光标离开引用）立即变成链接，无需切换视图
- 光标落在引用上时保持原文以便编辑；非光标行由 Obsidian 渲染管线处理
- 链接目标统一为 `<中文全名> <章>#<节>`（英文输入也链到中文库结构）
- 列表中每节独立链接，可分别点击跳转；范围引用整段一个链接指向第一节
- **范围引用 hover 段落预览**：鼠标移入 `太 25:36-38`，弹出浮层显示 36–38 **连续几节**的内容（按分隔线分节），浮层内的内链仍可点击跳转；单节引用走 Obsidian 原生页面预览
- 链接可点击跳转，支持 hover 页面预览（需开启核心插件"页面预览"）
- 自动跳过代码块、行内代码、数学公式与已有链接
- 误报保护：`大约 25:36`、`约 30 人`、`参考 25:36` 均不会误识别
- 引用匹配不跨行：书卷名与章号之间的换行不参与匹配，`导出\n00:36–01:08` 这类时间戳行不会误报
- 章/节号禁前导零：`00:36`、`01:08` 等时间戳（第 0 章/前导零章号）不识别
- 嵌套兜底：命中文本已含 `[[`/`]]` wikilink 语法时不再包裹，杜绝嵌套爆炸
## 永久转换（写入文件）

把引用永久改写为 Obsidian 内链，**显示文本不变**（别名语法）：

```
太 25:36-38  →  [[马太福音 25#36|太 25:36-38]]
```

- **命令面板**：
  - `转换当前文件的圣经引用为内链`
  - `转换整个库的圣经引用为内链`（带确认弹窗，遍历全部 Markdown 文件）
- **自动转换**（设置中开关）：
  - 打开文件时自动转换（默认**开**，防抖 800ms）
  - 编辑后 3 秒自动转换（默认**关**，防光标跳动，建议用命令）
- 转换后所有视图（阅读 / Live Preview / 源码模式）均为链接，hover 预览与点击跳转不变
- 已转换的 `[[...|...]]` 不会被重复转换；未转换的引用仍由实时渲染兜底
- **表格内引用用 `\|` 转义**：写入 `[[马太福音 25#36\|太 25:36]]`，`\|` 不会被当作表格列分隔符，Obsidian 正常解析为别名链接，表格结构不受影响

## Hover 段落预览的要求

- **范围引用**（如 `太 25:36-38`）hover 弹出连续几节浮层；**单节引用**走 Obsidian 原生页面预览
- 三类链接全覆盖：未转换引用（实时渲染链接）、编辑器内链接（CM6 widget）、**永久转换后的原生 wikilink**（hover 时从链接显示文本重新解析范围）
- 多节链接 hover 时在 document 捕获阶段拦截事件，**只显示多节浮层**，Obsidian 原生页面预览被阻止（无双层预览）；单节/非圣经链接不受影响，走原生页面预览
- 章笔记文件按 Obsidian 链接解析（支持库内**任意子文件夹**），也匹配笔记名 `马太福音 25.md`
- 每节需有**纯节号标题**（如 `# 36`、`## 36`），插件据此抓取 36 到 38 各节内容
- 中途缺节时预览截断到最后一个连续节；起始节不存在则不弹浮层
- 找不到章笔记时弹一次性 Notice 提示（每章只提示一次）
- 单节链接的原生预览需开启核心插件"页面预览"

## 安装

### 从 GitHub 下载（仓库根目录即插件三件套）

1. 克隆或下载本仓库，把 `manifest.json`、`main.js`、`styles.css` 复制到：

   ```
   <你的库>/.obsidian/plugins/bible-ref-linker/
   ```

2. Obsidian → 设置 → 第三方插件 → 启用 **Bible Ref Linker**

### 本地开发

```bash
git clone https://github.com/stickgoal/obsidian-bible-ref-linker.git
cd obsidian-bible-ref-linker
npm install
npm run build
# 然后把 main.js / manifest.json / styles.css 复制到
# <你的库>/.obsidian/plugins/bible-ref-linker/
```

## 开发

```bash
npm install
npm test        # 解析器单元测试（node 原生运行，无需 obsidian 环境）
npm run build   # 类型检查 + 打包 main.js
npm run dev     # watch 模式
```

## 已知边界

- 链接目标结构固定为 `<书卷全名> <章>#<节>`，请确保库中存在对应笔记（如 "马太福音 25.md"，内有 `# 36` 标题）
- 裸"书卷 + 数字"（如 `太 25`，无冒号/章字）不识别——避免"约 30 人"这类副词用法误报，整章引用请写 `太 25章` 或 `太 第25章`
- 顿号/逗号列表不能跨章（`太 25:36、26:1`），跨章请用分号
- 中文数字章节（如 `太二十五36`）暂不支持
- 表格行内转换会写入 `\|` 转义形式（如 `[[马太福音 25#36\|太 25:36]]`），这是 Obsidian 表格内别名链接的标准写法
- **永久转换的保护区间**：YAML frontmatter、围栏代码块（``` / ~~~）、行内代码、数学公式（`$$` 块与行内 `$...$`）、Markdown 链接文本 `[text](url)` 内的引用一律不转换，渲染层与编辑器装饰同步跳过
- 行内 HTML 标签（如 `<span>太 25:36</span>`）内的引用罕见且 Obsidian 不解析其中的 wikilink，未做特殊处理
- 章号/节号不允许前导零（`出 03:16` 不识别）；如笔记中已被旧版本污染（嵌套 `[[...|[[...` 格式），需手动清理损坏文本，新版不会再恶化
